# Roadmap

1. **Foundation**: project setup, settings (Home Assistant address and token), connection test.
2. **Flow diagram**: animated dashboard of the heat pump (own graphics, not copied from Thermia).
3. **History**: charts with Swift Charts.
4. **Menus**: a menu structure that follows the pump's own (Information, Service and so on), read-only.
5. **Alarms**: alarm and history view.
6. **Language**: Swedish and English, selectable in settings.
7. **iPad layout.**
8. **Later, maybe**: writing settings. Not planned until the read-only app is solid.
